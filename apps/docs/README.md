# 📚 Documentation Workspace

This workspace is dedicated to hosting the developer documentation site for the template.

## Recommendations
To establish a documentation platform, it is recommended to install **Astro** with the **Starlight** documentation theme:

```bash
# Initialize Starlight documentation in this folder
pnpm create astro@latest --template starlight
```

### Starlight Features
- Out-of-the-box markdown and MDX support.
- Built-in search functionality.
- Fully responsive layout with dark mode support.
- Internationalization support.
