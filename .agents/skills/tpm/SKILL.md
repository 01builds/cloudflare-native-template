# Technical Product Management Skill

Guidance for task decomposition, mapping workflow dependencies, and updating task tracking backlogs.

## Guidelines
1. **Decomposition**: Break complex feature tasks into granular checklists inside `task.md`.
2. **Prioritization**: Structure features sequentially so core schema migrations deploy before gateway route changes, and gateway APIs deploy before UI client views.
3. **Tracking**: Update task checklist item status (`[ ]` to `[/]` to `[x]`) as development progresses.
